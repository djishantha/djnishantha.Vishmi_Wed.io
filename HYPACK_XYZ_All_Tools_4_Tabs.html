CHN → XYZ Nodes Only

Select a HYPACK CHN file.

The converter extracts the channel nodes only.

The output contains:

X Y Z

Node numbers, faces, segments, labels and other CHN information are not included.

CHN output example:

979390.720 179494.630 37.470
979395.120 179498.210 37.520
979401.330 179502.440 37.610

Only X, Y and Z are written.

HYPACK XYZ VDATUM Z Adjuster

Match every survey XYZ point to the closest VDATUM XY point and calculate the adjusted Z value.
========================================= VDATUM FILE =========================================

1. Select VDATUM XYZ File

No VDATUM file selected
Select the VDATUM XYZ file containing X, Y and Z values.
========================================= SURVEY FILE =========================================

2. Select Survey / Second XYZ File

No survey file selected
X and Y from this file will be retained. The Z value will be adjusted using the closest VDATUM point.
========================================= CALCULATION =========================================

Calculation

New Z = Survey Z + VDATUM Z
For every point in the survey file, the program finds the VDATUM point with the closest X and Y location.
Example:

Survey Z = 8.30
VDATUM Z = -0.71

New Z = 8.30 + (-0.71) = 7.59

HYPACK XYZ Z Value Adjuster

Adjust or invert the Z values in a HYPACK XYZ text file. X and Y values remain unchanged except for output rounding.

Input:
979419.277 179385.831 -4.078

Output:
979419.28 179385.83 -4.1

Rounding:
X = 2 decimals
Y = 2 decimals
Z = 1 decimal
Operations:
Enter 1.5 → adds 1.50 to every Z value
Enter -2.2 → subtracts 2.20 from every Z value
Check Invert Z Values → changes positive Z to negative and negative Z to positive

Output rounding:
X → 2 decimal places
Y → 2 decimal places
Z → 1 decimal place
