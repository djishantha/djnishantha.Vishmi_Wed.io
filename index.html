HYPACK MTX & CHN to XYZ Converter

Convert HYPACK files directly in your browser.

MTX: Creates an XYZ file containing only the four outside corner coordinates.
CHN: Extracts the channel nodes and creates an X Y Z XYZ file.

1. MTX → Four Corner XYZ

Select a HYPACK MTX file. The MTX values are interpreted as:

X
Y
Width
First Leg / Length
X Grid Spacing
Y Grid Spacing
Bearing from North

Bearing is measured clockwise from North.

Example MTX values:

1223885.40
186682.92
486.00
795.00
3.00
3.00
16.80

Result:
1223885.400 186682.920 0.0
1224115.180 187443.989 0.0
1224580.438 187303.520 0.0
1224350.657 186542.451 0.0

2. CHN → XYZ Nodes Only

Select a HYPACK CHN file. The converter extracts the channel nodes only.

The output contains:
X Y Z

Node numbers, faces, segments, labels and other CHN information are not included.

CHN output example:

979390.720 179494.630 37.470
979395.120 179498.210 37.520
979401.330 179502.440 37.610

Only X, Y and Z are written.
